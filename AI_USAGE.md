# Использование AI

## Какие части делались с AI

- Mock Server
- Конфигурация Docker
- Unit-тесты
- Весь остальной boiler-plate

## Какие решения кандидат принял сам

- Архитектура и FSD-границы
- Review и доводка всего AI-кода
- UI/UX решения

## Какие AI-предложения были отклонены

- E2E/Playwright и Snapshot-тесты вместо точечных unit
- Избыточные `useMemo`/`useCallback` «на всякий случай»
- Предложение создать дизайн-систему с нуля
- i18n-ключи английскими строками в коде «для простоты»
- any / ослабление типов

## Какие места кандидат проверял особенно внимательно

- Вёрстку и соответствие ТЗ
- Валидация схем для форм
- Корректность мапперов

## Что бы кандидат улучшил при наличии ещё одного дня

- Optimistic Update при добавлении ставку
